# วิธีการติดตั้ง Google Apps Script สำหรับระบบบันทึกหะละเกาะฮฺ

สคริปต์ในโฟลเดอร์นี้ทำหน้าที่เป็น Backend API เชื่อมต่อระหว่างเว็บแอปพลิเคชันกับ Google Sheets โดยมีความปลอดภัยและระบบป้องกันการบันทึกซ้อน

---

## ขั้นตอนการติดตั้ง (ใช้เวลาประมาณ 3 นาที)

### 1. สร้าง Google Sheets
1. ไปที่ [Google Sheets](https://sheets.new) แล้วสร้างสเปรดชีตใหม่
2. ตั้งชื่อไฟล์ตามต้องการ เช่น `ฐานข้อมูลหะละเกาะฮฺ`

### 2. นำโค้ดไปวางใน Apps Script
1. ที่เมนูด้านบนของ Google Sheets คลิก **ส่วนขยาย (Extensions)** > **Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด
3. คัดลอกโค้ดทั้งหมดจากไฟล์ [`google-apps-script/Code.gs`](./Code.gs) ไปวาง
4. กดปุ่ม **บันทึก (Save)** (ไอคอนแผ่นดิสก์ หรือ `Ctrl+S` / `Cmd+S`)

### 3. สร้างตารางและข้อมูลตัวอย่างอัตโนมัติ
1. ที่แถบเครื่องมือด้านบน เลือกฟังก์ชัน `initialSetup`
2. กดปุ่ม **เรียกใช้ (Run)**
3. จะมีหน้าต่างขึ้นมาขอสิทธิ์การเข้าถึง (Authorization Required) ให้กดยอมรับสิทธิ์ (เลือกบัญชี Google ของท่าน > Advanced > Go to Untitled project (unsafe) > Allow)
4. เมื่อรันเสร็จ ให้กลับไปดูที่ Google Sheets จะพบว่ามีทั้ง 6 ชีตสร้างขึ้นมาพร้อมหัวตารางและข้อมูลตัวอย่างเรียบร้อย:
   - `Members` (สมาชิก)
   - `Sessions` (งวดการนัดพบ)
   - `Payments` (รายการรับเงิน)
   - `Expenses` (รายการรายจ่าย)
   - `Attendance` (การเช็คชื่อ)
   - `Config` (การตั้งค่า)

### 4. เปลี่ยนรหัส PIN ผู้ดูแลระบบ (ค่าเริ่มต้นคือ `123456`)
- สามารถเปลี่ยนได้ 2 วิธี:
  - **วิธีที่ 1 (ผ่านโค้ด):** เลือกฟังก์ชัน `setAdminPin` แล้วแก้ไขพารามิเตอร์ เช่น `setAdminPin("998877")` แล้วกด Run
  - **วิธีที่ 2 (ผ่านการตั้งค่า):** ไปที่เมนูซ้าย **การตั้งค่าโครงการ (Project Settings)** (ไอคอนฟันเฟือง) > เลื่อนลงไปที่ **คุณสมบัติของสคริปต์ (Script Properties)** > แก้ไขค่า `ADMIN_PIN` เป็นรหัสที่ต้องการ

### 5. Deploy เป็น Web App
1. คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** ที่มุมบนขวา > เลือก **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. คลิกไอคอนฟันเฟืองที่ "เลือกประเภท (Select type)" > เลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `Halaqah API v1`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me / your-email@gmail.com)` *(สำคัญมาก!)*
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก! เพื่อให้หน้าเว็บเรียก API ได้โดยไม่ต้องล็อกอินบัญชี Google)*
4. กด **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL เว็บแอป (Web app URL)** ที่ลงท้ายด้วย `/exec`
   (ตัวอย่าง: `https://script.google.com/macros/s/AKfycb.../exec`)

### 6. นำ URL ไปใส่ในโปรเจกต์เว็บ
นำ Web App URL ที่ได้ไปใส่ในไฟล์ `.env` ของโปรเจกต์เว็บ:
```bash
VITE_API_URL="https://script.google.com/macros/s/AKfycb.../exec"
```
*(หากยังไม่ได้ Deploy หรือเปิดใช้งานแบบ Offline ระบบจะมี Mock Data อัตโนมัติให้ทดสอบการทำงานได้ทันที)*
